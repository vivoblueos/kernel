# Resource Guards Must Be Marked must_use

When generating a Rust resource guard type, add `#[must_use]` to the type definition.

A resource guard is an RAII type that holds a resource, lock, borrow, or temporary state and releases the resource or restores state when dropped. Cleanup may be implemented directly in `Drop` or delegated to guard fields. Identify guards by their responsibilities, not only by a name ending in `Guard`.

## Rules

- Add a type-level `#[must_use]` attribute to every new resource guard `struct` or `enum`. When modifying an existing guard, add the attribute if it is missing.
- An attribute on a constructor, factory function, or method returning a guard does not replace the required type-level attribute.
- When a macro generates a guard, include the attribute on the type definition emitted by the macro.
- An existing `#[must_use]` or `#[must_use = "explanation"]` satisfies the requirement. Do not add a duplicate attribute.
- Preserve existing resource management and `Drop` behavior. Avoid unrelated changes when adding the attribute.

## Existing Examples in This Repository

The following types in `kernel/` already have type-level `#[must_use]` attributes. Use them as references when generating similar guards.

| Types | Source | Guard behavior |
| --- | --- | --- |
| `DisableInterruptGuard`, `PlainDisableInterruptGuard` | [support.rs](../../../kernel/kernel/src/support.rs) | The former restores the saved local interrupt state in `Drop`; the latter re-enables local interrupts in `Drop`. |
| `PreemptGuard` | [thread/mod.rs](../../../kernel/kernel/src/thread/mod.rs) | Calls `enable_preempt()` on its thread in `Drop`. |
| `SpinLockGuard`, `SpinLockReadGuard` | [sync/spinlock.rs](../../../kernel/kernel/src/sync/spinlock.rs) | Hold the underlying lock guard and an optional interrupt guard. Cleanup occurs through their fields when dropped. |
| `RwLockReadGuard`, `RwLockWriteGuard`, `RwLockUpgradableGuard` | [tinyrwlock.rs](../../../kernel/infra/src/tinyrwlock.rs) | Update the reader count or clear lock state in `Drop`. |
| `__BlueOSTestDoneGuard` | [test_harness/src/lib.rs](../../../kernel/test_harness/src/lib.rs) | Generated inside a `quote!` block with `#[must_use]`; increments the completion counter and wakes waiters in `Drop`. |

Actual type definition from `kernel/kernel/src/support.rs`:

```rust
#[derive(Debug)]
#[must_use]
pub struct DisableInterruptGuard {
    old: usize,
}
```

Before delivery, check every resource guard generated or modified in the task. Confirm that the attribute is on the type definition, including types generated by macros.
