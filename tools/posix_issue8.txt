#
# POSIX.1-2024 (IEEE Std 1003.1-2024, The Open Group Base Specifications
# Issue 8) interfaces that Issue 7 did not have.
#
# Issue 7 (2017) was a reprint of the 2008 edition plus two technical
# corrigenda and added no interfaces, so this file is the complete delta
# between the two most recent POSIX revisions.
#
# Format: one interface per line.
#   <header> <symbol> <tier>
#
# tier:
#   required  POSIX.1-2024 conformance needs it. Omitting one of these means
#             the implementation is not Issue 8 conformant.
#   optional  Part of Issue 8, but it depends on a capability that is not a
#             kernel capability, so it can be scheduled later without
#             blocking a conformance claim.
#   deferred  Part of Issue 8, but it needs a kernel capability that is still
#             on the roadmap (process model, credentials, ELF loading).
#
# The audit tool reports, for each interface, whether librs exports it and
# whether a conformance case covers it.
#
